# Security Policy

## Supported Versions

Security updates will be applied to the following versions of toml.min:

| Version | Supported          |
| ------- | ------------------ |
| ^0.8.x  | :white_check_mark: |
| < 0.8.x | :x:                |

## Reporting a Vulnerability

Please report any vulnerability on the following page: https://github.com/wellwelwel/toml.min/security/advisories
